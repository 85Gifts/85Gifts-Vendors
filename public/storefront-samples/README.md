# Storefront sample images

Demo imagery used by `scripts/storefront-mock.js` for local storefront previews.
These are **not** production vendor uploads; real storefront images come from the
backend.

All photos are from [Unsplash](https://unsplash.com) and are used under the
[Unsplash License](https://unsplash.com/license). Source photo IDs are listed
below so each asset can be traced and re-downloaded.
